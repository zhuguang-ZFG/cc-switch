# ai.168661 NewAPI / OMP channels (2026-08-14)

## Scope

Three independently authorized keys for `https://ai.168661.xyz/v1` were
validated and installed through the local NewAPI management API. Credentials
remain only in the NewAPI SQLite SSOT; no key is stored in this repository or
in this document.

For direct upstream calls the API root is `https://ai.168661.xyz/v1`. NewAPI
type-1 channels store `base_url=https://ai.168661.xyz` because NewAPI appends
`/v1/chat/completions`; storing `/v1` in the channel would produce a double
`/v1/v1/...` request path.

Grok mapping.

Grok image and video ids were visible in `/v1/models` but were intentionally
not attached to the coding channel. The chat-completions contract was not used
to infer image/video generation compatibility.

## OMP registration

The existing `zg-newapi/grok-4.5` registration remains the supported OMP Grok
selector. Two additional selectors were added to `~/.omp/agent/models.yml`:

- `zg-newapi/deepseek-v4-flash-0731`: 380k context, 128k output, reasoning,
  text and image input. The limits follow the existing DeepSeek V4 Flash
  registration; image input was verified end to end with an actual PNG.
- `zg-newapi/hy3`: 196608 context, 32768 output, reasoning, text input. The
  context/output posture follows the previously deployed HY3 operational
  contract, while reasoning support was confirmed from the new upstream.

The repository helper `scripts/ops/update_ai168661_omp_models.mjs` performs an
idempotent, atomic update and creates a byte-identical backup before writing.
It does not contain credentials or modify the installed OMP package.

## Backups and rollback

- NewAPI snapshot:
  `~/.new-api-local/backups/new-api-before-ai168661-channels-20260814-162540.db`
  (SQLite `integrity_check=ok`).
- OMP backup: `~/.omp/agent/models.yml.20260814-164105-ai168661.bak`.

Normal rollback is narrower than restoring the whole database: disable ch39,
ch78, and ch79 through `POST /api/channel/{id}/status`; delete ch78/ch79 only
after confirming no active traffic; restore ch39 and the four option values
from the database snapshot if the old Grok credential is required. Restore the
OMP backup atomically for model-registry rollback. A full database restore
requires stopping NewAPI first and is reserved for management-API rollback
failure.
